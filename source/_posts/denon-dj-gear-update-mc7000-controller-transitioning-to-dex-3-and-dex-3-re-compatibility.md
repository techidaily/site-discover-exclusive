## Denon DJ Gear Update: MC7000 Controller Transitioning to Dex 3 & Dex 3 Re Compatibility

[![Denon MC7000 Map for PCDJ DEX 3 and DEX 3 RE](https://i1.wp.com/pcdj.com/wp-content/uploads/2017/02/downloadmapformc7000-coverimage.jpg?resize=706%2C321&ssl=1)](https://i1.wp.com/pcdj.com/wp-content/uploads/2017/02/downloadmapformc7000-coverimage.jpg?fit=706%2C360&ssl=1 "Denon MC7000 Map for PCDJ DEX 3 and DEX 3 RE")

**Download the [Denon MC7000](http://9nl.at/dfgr) map for [DEX 3](https://tools.techidaily.com/pcdj/products/) and [DEX 3](https://tools.techidaily.com/pcdj/products/) RE below (the map file will also be included with the 3.8 installation when available)** 

Just like the Denon MC6000 MK2 predecessor the **Denon MC7000** is one serious bit of kit. A professional grade DJ controller in every aspect, it’s an ideal fit for [DEX 3](https://tools.techidaily.com/pcdj/products/) and [DEX 3 RE](https://tools.techidaily.com/pcdj/products/) users that need pro-ready features whether mixing music or music videos at the club or wedding reception.

[VIEW LARGER IMAGE ![Denon MC7000 DJ Controller Angled](https://i2.wp.com/pcdj.com/wp-content/uploads/2017/02/slider_01-1.jpg?fit=300%2C169&ssl=1 "Denon MC7000 DJ Controller Angled")](https://i2.wp.com/pcdj.com/wp-content/uploads/2017/02/slider%5F01-1.jpg?fit=1030%2C579&ssl=1)

Plug-and-play with [DEX 3](https://tools.techidaily.com/pcdj/products/) and [DEX 3 RE](https://tools.techidaily.com/pcdj/products/) (using the downloadable map file below, which will already come pre-loaded with version DEX 3.8 and above), the 4-Channel **MC7000** comes uniquely equipped with dual USB connections. With two USB audio interfaces the **Denon MC7000** allows for two DJs to play together simultaneously or ‘hand off’ without missing a beat. Coupled with Denon DJ’s robust build quality and 24-bit audio output, it is a no-compromise controller perfectly suited to both mobile and club DJs looking for the next evolution tactile control over [DJ software](https://tools.techidaily.com/pcdj/products/).

[VIEW LARGER IMAGE ![Denon MC7000 DJ Controller back](https://i2.wp.com/pcdj.com/wp-content/uploads/2017/02/slider_03.jpg?fit=300%2C169&ssl=1 "Denon MC7000 DJ Controller back")](https://i2.wp.com/pcdj.com/wp-content/uploads/2017/02/slider%5F03.jpg?fit=1030%2C579&ssl=1)

The **Denon MC7000** also includes dual 6-inch touch-capacity platters, 16 performance pads for triggering hot cues and loops (finger drumming galore), 2 mic inputs (karaoke anyone?), XLR booth and master connections as well as a digital mixer so mixing is done ‘internally’, making it a choice option for video mixing with DEX 3\. It’s a bit larger than the MC6000 MK2 but also less cramped. All this for only $999 with features on par with the Pioneer DDJ-SZ ($1,997) I’m sure the **MC7000** will quickly become one of the most popular pro-grade [DJ controllers](https://tools.techidaily.com/pcdj/products/) for [DEX 3 DJ software](https://tools.techidaily.com/pcdj/products/) users.

[Download The Denon MC7000 Map For DEX 3 And DEX 3 RE](https://tools.techidaily.com/pcdj/products/)

**INSTALLATION INSTRUCTIONS:** With DEX 3 closed – Unzip the Map (js file only) to: **Documents -> PCDJ-DEX3 -> Controllers**

_**Note:** If you’re already running DEX 3 or DEX 3 RE version 3.8 or above you do not need to install the map below – it’s already included with installation._

### DENON MC7000 FEATURES

* 4-channel DJ controller with digital mixer
* Dual USB audio interfaces—connect 2 computers at once
* 16 velocity-sensitive performance pads
* New dedicated key-matching and changing controls
* Solid 6-inch touch-capacitive platters
* 2 mic inputs with dedicated controls
* XLR booth and master connections
* Serato DJ DVS-compatible
* Solid compact design

**Package Contents**

* MC7000
* Power Adapter
* USB Cable
* Quickstart Guide
* Software Download Card
* Safety and Warranty Manual

* WINDOWS: Windows 7, Windows 8.1, Windows 10
